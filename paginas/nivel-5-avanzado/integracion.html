6Integración con otros programas

ProgramaTipo de integración
RevitModelo BIM se exporta a AutoCAD para planos de detalle y fabricación.
SketchUpModelos 3D se importan como bloques o sólidos para referencia.
Civil 3DExtensión de AutoCAD para ingeniería civil: topografía, redes y pavimentos.
3ds MaxModelos 3D de AutoCAD se importan para renderizado fotorealista.
NavisworksCoordination: combina modelos de varias disciplinas para detectar choques.
Excel / hojas de cálculoTablas y listas de áreas se extraen con EXTRAERDATOS (en inglés: DATAEXTRACTION).

Los formatos de intercambio más usados son .DWG (nativo), .DXF (intercambio entre CADs), .IFC (BIM) y .SAT (ACIS sólidos).

Llevar datos de AutoCAD a Excel

1

Lanza la extracción

Con EXTRAERDATOS (en inglés: DATAEXTRACTION) se abre el asistente para crear una tabla de datos del dibujo.

2

Elige qué extraer

Selecciona bloques o atributos (por ejemplo puertas: nombre, dimensiones, cantidad).

3

El destino

Escoge insertar la tabla en el dibujo o exportarla a .xls para seguir trabajando en Excel.

Integraciones típicas

ProgramaCómo integra
ExcelDATALINK vincula tablas en vivo; DATAEXTRACTION exporta información.
SketchUpImporta/exporta DXF o 3DS para bocetos de presentación.
RevitFlujo BIM: IFC / DWG convertido como base topológica.
GISMAPCONNECT conecta capas SHP/WMS y exporta geometría con datos.
Consejo Cuando integres con otro programa, usa formatos neutros (DXF, IFC, PDF) salvo que el flujo admita DWG nativo. Así evitas incompatibilidades de versión entre aplicaciones.
