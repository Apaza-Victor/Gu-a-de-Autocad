10Campos (Fields)

Un campo es un texto que se actualiza automáticamente con información del dibujo: fecha de modificación, nombre de archivo, área de un polígono, autor, etc. Son esenciales para cajetines y tablas dinámicas.

Campos más usados

CampoCategoríaQué muestra
Nombre de archivoDocumentoEl nombre del archivo .DWG actual.
Fecha de creaciónDocumentoLa fecha y hora de creación del archivo.
Fecha de modificaciónDocumentoCuando se guardó por última vez.
AutorDocumentoEl nombre configurado en las preferencias.
Área de un objetoObjetoEl área calculada de una polilínea, círculo o región cerrada.
LongitudObjetoLa longitud de una polilínea o línea.

Insertar un campo

  1. Escribe un texto con TEXTM (en inglés: MTEXT) y haz clic derecho → Insertar campo.
  2. Selecciona la categoría y el campo específico.
  3. Configura el formato (fecha, decimales) y acepta.
  4. Para actualizar todos los campos del dibujo, escribe UPDATEFIELD.
Uso práctico En el cajetín de un plano, el campo de "Fecha" se actualiza solo cada vez que guardas. Nunca tendrás que escribir la fecha manualmente en cada impresión.

Otras categorías de campos útiles

CampoCategoríaQué muestra
Número de lámina / Nombre de láminaConjunto de planos (Sheet Set)El dato del Sheet Set asignado a esa hoja.
Fecha / HoraSistemaFecha y hora del sistema al actualizar el campo.
Escala de la ventana gráficaObjetoLa escala activa del viewport (ej. "1:50").
PerímetroObjetoEl perímetro cerrado de una polilínea o región.

Mini ejercicio: cajetín con área automática

1

Inserta el campo

Dentro de un TEXTM (en inglés: MTEXT) en el cajetín, clic derecho → Insertar campo → categoría Objeto → Área.

2

Selecciona la geometría

Con el botón de selección elige la polilínea cerrada que limita la planta (define antes el contorno con CONTORNO (en inglés: BOUNDARY) si no existe).

3

Actualiza con el campo

Acepta y, al cambiar la geometría, ejecuta UPDATEFIELD o recarga el campo con clic derecho → Actualizar campo: el área se recalcula sola.

Error común Pensar que el campo se actualiza en cada guardado por sí mismo. Se actualiza al REGENERAR (en inglés: REGEN), al imprimir o con UPDATEFIELD; si el plano muestra un dato viejo, comprueba primero que el campo esté reciente.
