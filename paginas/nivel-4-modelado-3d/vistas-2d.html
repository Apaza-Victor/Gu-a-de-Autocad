17Extracción de vistas 2D desde el modelo 3D

La documentación de entrega (planos constructivos, planos de fabricación) suele requerir vistas 2D acotadas aunque el modelo exista en 3D. Convertir el 3D en 2D evita redibujar y garantiza que los planos coincidan exactamente con la geometría modelada.

MétodoDónde se usaCaracterísticas
FLATSHOTEspacio modeloProyecta el modelo a una vista 2D plana de la orientación actual. Rápido y sencillo.
SOLVIEW / SOLDRAWLayoutsGenera vistas ortográficas y secciones en el espacio papel, con líneas ocultas y sombreados.
VIEWBASE / VIEWPROJAutoCAD modernoVistas base y proyectadas desde un modelo 3D, asociativas (se actualizan al cambiar el sólido).
¿Cuándo usar cada método? Usa FLATSHOT para una vista rápida en el espacio modelo. Usa SOLVIEW/SOLDRAW si trabajas en AutoCAD clásico con layouts y necesitas secciones. Usa VIEWBASE en AutoCAD moderno cuando quieras vistas asociativas que se actualicen solas al modificar el modelo.

Vistas base y proyectadas con VIEWBASE

1

Ve al layout

Pasa a una presentación y activa la pestaña Dibujo base → Desde el modelo 3D (o escribe VIEWBASE).

2

Coloca la vista base

Selecciona el sólido y sitúa la vista en el layout; elige escala y orientación (superior, frontal...).

3

Proyecta las vistas

Con VIEWPROJ arrastra las vistas proyectadas (planta, alzado, perfiles) desde la base.

4

Trabaja asociativo

Si cambias el modelo, las vistas se actualizan: clic derecho → Actualizar. Esto es lo que NO conseguías con FLATSHOT.

¿Cuándo usar cada método, resumen?
  • FLATSHOT: vista rápida 2D en espacio modelo, sin asociatividad.
  • SOLVIEW/SOLDRAW: AutoCAD clásico, ideal para secciones y líneas ocultas en layouts.
  • VIEWBASE/VIEWPROJ: AutoCAD moderno, asociativas y la vía recomendada para planos de taller.
