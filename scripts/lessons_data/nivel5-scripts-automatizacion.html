Un script (archivo .SCR) es una secuencia de comandos de AutoCAD escrita línea por línea, justo como la teclearías tú. Sirve para repetir tareas largas y para estándares: configurar capas, insertar un bloque cajetín, imprimir una tanda de planos o limpiar un archivo.

1. Script vs. AutoLISP

CriterioScript (.SCR)AutoLISP (.LSP)
FormatoTexto plano, secuencial, sin lógicaLenguaje de programación con variables y funciones
Curva de aprendizajeMínima (solo saber los comandos)Media: paréntesis, variables, condicionales
Bueno paraRutinas de una sola vez, configurar, imprimirAutomatizaciones reutilizables y con decisiones
Dentro del script—Puedes invocar una función LISP cargada

2. Escribir tu primer script

Cada línea del archivo se escribe como si la ejecutaras en la línea de comandos, terminando con una pulsación de Enter (la propia nueva línea ya lo representa). Este ejemplo crea tres capas:

capas.scr 
-CAPA
          N
          Ejes
          N
          Muros
          N
          Mobiliario

        ZOOM
        A
Regla de oro Escribe el guión largo delante del comando cuando esperes un cuadro de diálogo: -CAPA (en inglés: -LAYER) usa la versión por línea de comandos. Si escribes CAPA normal, el script se detiene esperándote en el diálogo.

3. Ejecutar y controlar el script

  • GUION (en inglés: SCRIPT): carga y ejecuta el .SCR seleccionado.
  • RSCRIPT: repite el script desde el principio (útil en bucles de animación o pruebas).
  • RETOMAR (en inglés: RESUME): continúa un script detenido por un error o por la tecla Esc.
  • RETARDO (en inglés: DELAY): pausa el script una cantidad de milisegundos.

4. Automatizaciones útiles

1

Configurar un dibujo nuevo

Limpiar capas base, fijar unidades y cajetín en un solo paso.

2

Imprimir plano por plano

Para cada layout: IMPRIMIR (en inglés: PLOT) → Enviar al archivo → cambiar nombre → siguiente. Se hace en una sola ejecución.

3

Limpieza de archivos heredados

PURGAR (en inglés: PURGE) → AUDITAR (en inglés: AUDIT) → guardar con GUARDARCOMO (en inglés: SAVEAS) en .DWG 2018 para estandarizar la entrega.

Cuidado con los cuadros de diálogo Si un script ejecuta un comando que abre diálogo y das Enter, algunos diálogos tienen predeterminada la acción "Cancelar": usa siempre la versión con guión (-CAPA, -ESTILOACOT en inglés: -ACOESTILO (en inglés: -DIMSTYLE), -IMPRIMIR en inglés: -IMPRIMIR (en inglés: -PLOT)) cuando automatices.

5. Scripts en dibujos de la red

En oficinas se usa el script como checklist ejecutable: al abrir un archivo entregado, corres el script de auditoría que revisa capas, cotas y purga. Si algo no responde, el script lo notifica en la salida de comandos, así se estandariza la revisión sin depender de la memoria de nadie.

6. Mini ejercicio: guion de nueva obra

1

Inicia en un dibujo

Crea obra.scr con tus capas base y el bloque cajetín insertado en las coordenadas del formato.

2

Prueba el script

Guarda el archivo con GUION (en inglés: SCRIPT) y arrastra el .SCR hasta AutoCAD si está en modo "abrir con".

3

Bucle de prueba

Con RSCRIPT repite la rutina y usa RETARDO (en inglés: DELAY) para no saltarte ningún mensaje.
