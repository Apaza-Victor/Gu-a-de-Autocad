2Herramientas de modificación

Permiten transformar objetos ya dibujados sin volver a trazarlos desde cero.

HerramientaComandoAtajoUso
MoverMOVER (en inglés: MOVE)MTraslada objetos de un punto base a un punto destino.
CopiarCOPIAR (en inglés: COPY)COIgual que mover, pero conserva el original.
RotarGIRAR (en inglés: ROTATE)GIGira objetos un ángulo respecto a un punto base.
EscalarESCALAR (en inglés: SCALE)SCAumenta o reduce el tamaño respecto a un punto base.
RecortarRECORTAR (en inglés: TRIM)RRElimina la parte de un objeto que sobrepasa un límite.
AlargarEXTENDER (en inglés: EXTEND)EXExtiende un objeto hasta tocar un límite de referencia.
DesfaseDESFASE (en inglés: OFFSET)DFCopia paralela a una distancia exacta (ideal para muros).
SimetríaREFLEJAR (en inglés: MIRROR)SIRefleja objetos respecto a un eje.
MatrizMATRIZ (en inglés: ARRAY)ARRepite objetos en filas/columnas, en círculo o a lo largo de una ruta.
EmpalmeREDONDEAR (en inglés: FILLET)EMPUne dos líneas con un arco de radio definido.
ChaflánCHAMFERCHAUne dos líneas con un corte recto en la esquina.
Flujo típico Un muro en planta suele dibujarse así: PLINE para el eje → OFFSET para dar el espesor → TRIM para limpiar las esquinas → FILLET con radio 0 para unir vértices sueltos.

Opciones que cambian el resultado

Detalles de los modificadores que más diferencias marcan en planos reales:

  • MIRROR y texto: la variable MIRRTEXT en 0 hace que los textos no se inviertan al reflejar; en 1 los copia en espejo.
  • FILLET con radio 0: une dos líneas cortando las esquinas sobrantes. Es la vía más rápida para "limpiar" vértices que no tocan.
  • OFFSET en modo múltiple: la opción O (Multiple) repite el desfase sin reiniciar el comando (ideal para muros paralelos).
  • ROTATE y SCALE con referencia: la opción R (Reference) alinea el objeto a una medida conocida sin calcular ángulos.
ComandoOpción prácticaUso típico
MATRIZ (en inglés: ARRAY)Rectangular / Polar / PathRepetir pilares en retícula, luminares en círculo o muros a lo largo de un eje curvo.
RECORTAR (en inglés: TRIM) / EXTENDER (en inglés: EXTEND)Pulsa Enter tras seleccionarRecorta/extiende contra todos los objetos como límite.
COPIAR (en inglés: COPY)Modo múltiple + desplazamientoCopiar una pieza a varias posiciones sin repetir el comando.
Error común Olvidar el punto base en COPY/MOVE/ROTATE/SCALE. Si eliges un punto lejano, el objeto "salta" a un destino inesperado. Usa siempre un punto apoyado en el objeto (esquina u OSNAP END).

Mini ejercicio: simetría de puertas con MIRRTEXT=0

1

Prepara el conjunto

Dibuja una puerta con RECTÁNGULO (en inglés: RECTANG) más un texto TEXTO (en inglés: TEXT) "Puerta 01" junto a ella.

2

Refleja correctamente

Pon MIRRTEXT en 0, selecciona puerta y texto, haz REFLEJAR (en inglés: MIRROR) con eje vertical y comprueba que el texto queda legible.

3

Limpia con radio 0

Haz REDONDEAR (en inglés: FILLET) → R → 0 entre las dos líneas de cada esquina para cerrar el contorno sin arcos sobrantes.
