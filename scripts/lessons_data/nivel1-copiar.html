COPIAR crea duplicados de un objeto en el mismo dibujo. Como MOVER, se basa en un punto base y un destino, pero a diferencia de él, el original se queda en su sitio. Es una de las herramientas que más tiempo ahorra: una hilera de sillas, un muro repetido, una fila de pilares...

1. Ejecutar el comando

CómoQué escribirAtajo
Barra de comandosCOPIAR (en inglés: COPY)CO o CP
Cinta → Inicio → ModificarIcono de copiarClic

2. Cómo se usa

1

Selecciona y determina el punto base

COPIAR (en inglés: COPY) → selecciona el objeto → Enter → clic en el punto base (una esquina, un centro... ideal con OSNAP).

2

Varias copias en cadena

El comando se queda "pegando" puntos de destino: haz clic (o teclea @100,0) y AutoCAD sitúa copias una tras otra. Pulsa Enter para terminar.

3

Desplazamiento del modo array

Con A (Array) indicas cuántos objetos en total (incluido el original) quieres separados a una distancia; ideal para pilares o ejes repetidos.

3. Mini ejercicio

1

Copia una silla en una fila

Dibuja una silla simple (rectángulo 40×40 + asiento) en un extremo. COPIAR (en inglés: COPY) → selecciona → punto base en la esquina → teclea @120,0, @240,0, @360,0... hasta llenar la hilera con Enter.

2

Comprueba la distancia

Mide entre esquinas de sillas consecutivas con DISTANCIA (en inglés: DIST): deben quedar a 120 unidades.

Error común Confundir COPIAR (duplica con punto base, en pantalla) con el portapapeles del sistema (Ctrl+C / Ctrl+V). COPIAR no usa el portapapeles: crea copias del dibujo con precisión. El COPIARbase (en inglés: COPYBASE) sí sirve para pasar entre dibujos.
