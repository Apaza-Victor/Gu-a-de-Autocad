Ejemplos de comandos

Diagramas paso a paso que muestran exactamente qué hace cada comando: antes, después y cómo llegar ahí.

2D Plano completo

ESC 1:50

Un mismo dibujo reúne lo visto en la guía: muros por OFFSET, esquinas y puertas con FILLET, recortes con TRIM, muebles con RECTANGLE y ARRAY, y cotas en su propia capa.

CAPA: Muros · Cotas · Puertas UNIDADES: mm
Muros Cotas Puertas Mobiliario
Tip Este plano salió de LINE, OFFSET, TRIM, FILLET y ARRAY. Guarda cada tipo de objeto en su capa para poder congelar las cotas al imprimir.

ATAJOS Atajos de teclado de AutoCAD

F1–F12

Mapa completo de atajos de teclado de AutoCAD en una sola imagen: teclas de función (F1 a F12), navegación y los comandos de un solo toque (L para LINE, C para CIRCLE, O para OFFSET...). Imprímelo y tenlo junto al teclado mientras practicas.

Tip Empieza por F3 (OSNAP), F8 (ORTO) y F10 (rastreo polar): son los que más velocidad aportan al dibujar.

Dibujo LINE

L

Dibuja segmentos de línea recta entre puntos. Cada clic define el siguiente vértice.

Antes
Después
Tip Usa ORTO (F8) para que los segmentos salgan perfectamente horizontales o verticales.

Modificación OFFSET

O

Crea una copia paralela de un objeto a una distancia exacta. Fundamental para muros y estructuras.

Original
Resultado
Tip Después de OFFSET, usa TRIM para limpiar las esquinas donde los muros se cruzan.

Modificación TRIM

TR

Recorta la parte de un objeto que sobrepasa un límite de referencia.

Antes
Resultado
Tip En versiones recientes, presiona Enter después de TRIM y AutoCAD usa todos los objetos como límite automáticamente.

Modificación FILLET

F

Une dos líneas con un arco de radio definido. Con radio 0, une en esquina perfecta.

Antes
Resultado
Tip Para unir dos líneas sueltas en una esquina exacta, pon FILLET con radio = 0 y selecciona ambas líneas.

Modificación MIRROR

MI

Refleja objetos respecto a un eje simétrico definido por dos puntos.

Original
Resultado
Tip Útil para plantas simétricas: dibuja la mitad izquierda y refleja todo con MIRROR.

Modificación ARRAY

AR

Repite objetos en filas y columnas, en círculo o a lo largo de una ruta.

Original
ARRAY 3×4
Tip ARRAY POLAR distribuye objetos en círculo: ideal para tornillos, columnas circulares o asientos.

Precisión OSNAP

F3

Engancha el cursor a puntos exactos de los objetos: extremo, medio, centro, intersección.

Tip Mantén F3 activo siempre. Sin OSNAP es imposible dibujar con precisión real.

Capas LAYERS

LA

Las capas son como acetatos transparentes: agrupan objetos por categoría y controlan color, visibilidad y grosor.

Tip Nunca cambies el color de un objeto individualmente: asigna la capa correcta y deja que la capa controle el color.

3D EXTRUDE

EXT

Empuja un perfil 2D cerrado en línea recta para crear un sólido tridimensional.

Perfil 2D
Sólido 3D
Tip El perfil debe ser una polilínea cerrada o un region. Si usas LINE sueltas, primero usa JOIN para unirlas.

3D UNION / SUBTRACT

UNI / SU

Operaciones booleanas: fusionar (UNION) o restar (SUBTRACT) volúmenes de sólidos.

Dos sólidos
UNION
Mismos sólidos
SUBTRACT A-B
Tip SUBTRACT es el comando más usado para hacer perforaciones: taladros, vanos de puertas, recortes de material.

Modificación CHAMFER

CHA

Corta las esquinas de dos líneas con un ángulo recto (chaflán). A diferencia de FILLET, no usa arco.

Antes
Chaflán 15
Tip Útil en piezas mecánicas: define la distancia de chaflán en ambos lados o con ángulo y distancia.

Modificación EXTEND

EX

Extiende un objeto hasta tocar un límite de referencia. Es lo opuesto a TRIM.

Antes
Resultado
Tip Selecciona primero el límite (pared) y luego el objeto que quieres alargar.

Modificación STRETCH

S

Estira o comprime objetos moviendo vértices dentro de una selección cruzada.

Selección cruzada
Resultado
Tip La selección cruzada (de derecha a izquierda) es clave: solo los vértices dentro del recuadro se mueven.

Dibujo CIRCLE

C

Dibuja un círculo por centro y radio, por diámetro, o por tres puntos.

Tip C+D = círculo por diámetro. Útil cuando conoces el tamaño total, no el radio.

Dibujo RECTANGLE

REC

Dibuja un rectángulo a partir de dos esquinas opuestas. Opciones: esquina, centro, área.

Punto 1
Punto 2
Tip Escribe @largo,ancho para dimensiones exactas. Ejemplo: @100,50 crea un rectángulo de 100×50.

Dibujo HATCH

H

Rellena un área cerrada con un patrón visual: sólido, rayado, puntos, materiales.

Tip El área debe estar completamente cerrada. Si hay un hueco, el hatch se desborda fuera del área.

Modificación MOVE / COPY

M / CO

Traslada objetos de un punto base a un destino. COPY crea copias sin eliminar el original.

Original
Resultado
Tip Activa ORTO (F8) para mover solo en horizontal o vertical con precisión.

Modificación ROTATE

RO

Gira objetos un ángulo definido respecto a un punto base.

Original
Rotar 30°
Tip Escribe el ángulo en grados. Usa Reference para girar hasta un alineamiento específico.

Precisión Modo ORTO (F8)

F8

Restringe el cursor a movimientos perfectamente horizontales o verticales.

Sin ORTO
Con ORTO
Tip Actívalo siempre que dibujes líneas rectas de plano. Alterna con F8.

Precisión Cuadrícula y SNAP

F7 / F9

La cuadrícula visual ayuda a orientar el dibujo. SNAP engancha el cursor a los puntos de la cuadrícula.

Tip GRID solo es visual; SNAP es el que realmente mueve el cursor. Configura el espaciado en Drafting Settings.

Precisión DIM

DIM

Crea cotas que miden y documentan distancias, ángulos y radios en el plano.

Tip Usa DIMSTYLE para configurar una vez el aspecto de todas las cotas del proyecto.

Dibujo POLYGON

POL

Dibuja un polígono regular inscrito o circunscrito a un círculo.

Círculo guía
Hexágono inscrito
Tip Define el número de lados con el parámetro "Lados". Hexágonos y octágonos son los más comunes.

Dibujo ARC

A

Dibuja un arco por 3 puntos, por centro-inicio-fin o por radio.

3 puntos
Resultado
Tip Los arcos se trazan en sentido antihorario por defecto; para invertir la dirección, dibuja de derecha a izquierda.

Modificación SCALE

SC

Aumenta o reduce objetos respecto a un punto base sin cambiar su forma.

Original
Escala ×2
Tip Usa la opción "Referencia" para escalar un objeto hasta una longitud exacta.

Modificación EXPLODE

X

Descompone bloques, polilíneas o arrays en sus objetos individuales.

Bloque
Descompuesto
Tip Úsalo con cuidado: después de EXPLODE no puedes recuperar el bloque como unidad (a menos que lo reinsertes).

Modificación JOIN

J

Une líneas, arcos o polilíneas contiguos en un solo objeto.

Dos líneas
Polilínea
Tip JOIN es lo opuesto a EXPLODE: convierte dos muros en una polilínea continua y editable.

3D BOX

BOX

Crea un sólido rectangular primitivo definido por largo, ancho y alto.

Base 2D
Sólido
Tip Es la primitiva 3D más usada. Úsala como base para recortar con SUBTRACT.

3D SWEEP

SWEEP

Desplaza un perfil 2D a lo largo de una trayectoria curva para crear un sólido.

Perfil + ruta
Tubo
Tip Ideal para tuberías, molduras, rieles y cualquier forma con sección constante.

3D ORBIT

ORBIT

Navega libremente alrededor del modelo 3D para verlo desde cualquier ángulo.

Tip Mantén Shift + botón central del ratón para órbita libre. Escape para salir.

Capas Referencias externas (Xref)

XREF

Vincula archivos DWG externos como referencias. Se actualizan automáticamente cuando el archivo original cambia.

Tip Ideal para trabajo en equipo: cada profesional actualiza su parte y el plano colectivo se refresca solo.

Modificación PURGE y AUDIT

PU / AUDIT

PURGE elimina capas, bloques y estilos no usados. AUDIT corrige errores internos del DWG.

Antes
Después
Tip Ejecuta PURGE periódicamente para reducir tamaño. AUDIT después de un cierre inesperado.

Precisión Rastreo polar (F10)

F10

Muestra guías de ángulo exactas mientras dibujas (15°, 30°, 45°, 90°…) y el cursor se engancha a ellas.

Sin rastreo
Rastreo 45°
Tip Combinado con ORTO es lo más cercano a la precisión total. Configura los ángulos en Drafting Settings.

Capas BLOCK e INSERT

B / I

Agrupa objetos en un bloque reutilizable con un punto base. INSERT coloca copias con escala y rotación.

Objetos sueltos
1 bloque
Tip Los bloques reducen el archivo: 100 mesas = 1 definición de bloque + 100 inserciones ligeras.

Dibujo ELLIPSE

EL

Dibuja elipses definiendo el eje mayor, el eje menor y el centro.

Tip Escribe EL e indica los dos extremos del primer eje y la mitad del segundo. Útil para mesas y terrazas curvas.

Dibujo SPLINE

SPL

Dibuja curvas suaves que pasan por puntos de ajuste (fit points).

Puntos de ajuste
Curva suave
Tip A diferencia de los arcos, la curva no es un tramo circular perfecto: se adapta con suavidad a los puntos.

Dibujo MTEXT

T / MT

Crea texto multilínea con formato: negrita, alineación, columnas y justificación en un editor.

TEXT · 1 línea
MTEXT · párrafo
Tip Múltiples líneas dentro de un solo objeto MTEXT: ideal para rótulos, notas y cuadros de texto largos.

Modificación BREAK

BR

Rompe un objeto en dos partes eliminando el tramo entre dos puntos.

2 puntos
Resultado
Tip Para dividir sin dejar hueco, usa la opción @ del segundo punto: repite el primero y el objeto se parte en dos.

Modificación ALIGN

AL

Alinea y rota objetos de una sola vez tomando pares de puntos origen-destino.

Origen → destino
Alineado y rotado
Tip Con 3 pares de puntos también escala el objeto para ajustarlo, sin pasar por SCALE.

Dibujo DIVIDE

DIV

Coloca puntos o bloques a intervalos iguales a lo largo de un objeto sin partirlo.

Línea
DIVIDE en 5
Tip DIVIDE usa puntos invisibles (PDMODE). Activa el estilo de punto visible para verlos antes de dibujar.

3D REVOLVE

REV

Gira un perfil 2D alrededor de un eje para crear un sólido de revolución.

Perfil + eje
Sólido rotado
Tip REVOLVE genera vasos, columnas, tornos y todo lo que sea simétrico alrededor de un eje.

3D LOFT

LOFT

Crea un sólido que conecta dos o más secciones transversales con una transición suave.

Secciones
Transición suave
Tip LOFT con secciones de formas distintas produce transiciones orgánicas que EXTRUDE no puede lograr.

Dibujo TEXT

DT

Crea un texto de una sola línea definiendo el punto de inserción, la altura y la rotación.

Antes
Después
Tip Para rótulos cortos TEXT basta; para párrafos con formato usa MTEXT.

Precisión AREA

AA

Calcula el área y el perímetro de un recinto definido por puntos o de un objeto cerrado.

Antes
Después
Tip Pulsa O dentro de AREA para medir el área de un objeto cerrado con un solo clic.

Precisión DIST

DI

Mide la distancia y el ángulo entre dos puntos seleccionados del dibujo.

Antes
Después
Tip DIST informa también el ángulo de la línea respecto al eje X.

Capas LAYERISO

LAYISO

Aísla una capa: el resto se apaga o se atenúa para trabajar sin distracciones.

Antes
Después
Tip Para recuperar la visibilidad de todas las capas usa LAYUNISO.

Precisión DIMCONTINUE

DCO

Continúa una serie de cotas lineales encadenadas a partir de la última cota creada.

Antes
Después
Tip Primero crea una cota lineal con DIM y luego DCO añade segmentos encadenados.

Dibujo PLINE

PL

Dibuja polilíneas: secuencias de segmentos rectos y arcos que se comportan como un solo objeto.

Original
polilínea
Tip Pulsa A en medio del comando para insertar arcos, o C para cerrar la polilínea.

Dibujo CIRCLE TTR

C → TTR

Crea un círculo tangente a dos objetos y con un radio especificado.

Original
Resultado
Tip Elige la opción TTR dentro de CIRCLE y selecciona dos líneas o círculos.

Dibujo DONUT

DO

Dibuja anillos rellenos definiendo el diámetro interior y exterior.

diámetros
Resultado
Tip Un DONUT no es más que dos círculos concéntricos unidos como polilínea.

Dibujo XLINE

XL

Crea líneas de construcción infinitas que ayudan a alinear el dibujo.

Original
línea de construcción
Tip Usa XLINE como guías temporales: no afectan a la impresión si van en su propia capa.

Modificación PEDIT

PE

Edita polilíneas: une segmentos, convierte líneas o aplica curvaturas.

Original
polilínea
Tip Pulsa PE, selecciona una polilínea y usa J para unir líneas que compartan extremos.

Modificación MATCHPROP

MA

Copia las propiedades de un objeto (capa, color, tipo de línea...) a otros.

origen
Resultado
Tip Selecciona el objeto origen, luego MA y clic en los destinos. Doble MA aplica a todas las capas.

Modificación LENGTHEN

LEN

Alarga o acorta una línea, arco o polilínea sin mover el resto del dibujo.

Original
longitud
Tip Usa DY dentro de LEN para arrastrar el extremo con el cursor.

Modificación ARRAYPOLAR

AR·P

Crea copias de un objeto alrededor de un punto central.

Original
copias
Tip ARRAYPOLAR permite definir cuántas copias y si deben rotar siguiendo el círculo.

Precisión DIMSTYLE

D

Controla el aspecto de todas las cotas: flechas, texto, unidades y escala.

Original
Resultado
Tip Configura un estilo de cota una sola vez y reutilízalo en todo el proyecto.

Precisión UCS

UC

Mueve o rota el sistema de coordenadas para dibujar en planos inclinados o a medida.

plano de dibujo
Resultado
Tip Usa UCS + OB para alinear el sistema con un objeto existente.

Capas LINETYPE

LT

Cambia el patrón visual de una línea: continua, discontinua, punto y raya...

Antes
Después
Tip Carga tipos de línea con LT, y usa LTSCALE para ajustar el tamaño del patrón.

3D PRESSPULL

PULL

Convierte un recinto cerrado en un sólido o lo desplaza hacia dentro o fuera.

empujar
Resultado
Tip A diferencia de EXTRUDE, PRESSPULL estira o resta directamente pulsando en la cara.

3D SLICE

SL

plano de corte
Resultado
