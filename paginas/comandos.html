LINE L Dibujo Básico

Dibuja segmentos de línea recta entre puntos definidos por coordenadas o clics.

PLINE PL Dibujo Básico

Serie de segmentos rectos y curvos unidos como un solo objeto polilínea.

CIRCLE C Dibujo Básico

Dibuja un círculo por centro-radio, dos puntos, tres puntos u otras opciones.

ARC A Dibujo Básico

Tramo curvo definido por 3 puntos, centro-inicio-fin, u otras combinaciones.

RECTANG REC Dibujo Básico

Dibuja un rectángulo a partir de dos esquinas opuestas.

POLYGON POL Dibujo Básico

Polígono regular inscrito o circunscrito en un círculo.

ELLIPSE EL Dibujo Básico

Curva elíptica definida por eje mayor/menor o por centro.

SPLINE SPL Dibujo Intermedio

Curva suave que pasa por una serie de puntos de control.

MOVE M Modificación Básico

Traslada objetos de un punto base a un punto destino.

COPY CO Modificación Básico

Crea copias de objetos sin eliminar el original.

ROTATE RO Modificación Básico

Gira objetos un ángulo respecto a un punto base.

SCALE SC Modificación Básico

Aumenta o reduce el tamaño de objetos respecto a un punto base.

TRIM TR Modificación Básico

Recorta objetos hasta el límite de otro objeto de referencia.

EXTEND EX Modificación Básico

Extiende un objeto hasta tocar un límite de referencia.

OFFSET O Modificación Básico

Crea una copia paralela de un objeto a una distancia exacta.

MIRROR MI Modificación Básico

Refleja objetos respecto a un eje simétrico definido por dos puntos.

ARRAY AR Modificación Intermedio

Repite objetos en filas/columnas, en círculo o a lo largo de una ruta.

FILLET F Modificación Básico

Une dos líneas con un arco de radio definido (empalme).

CHAMFER CHA Modificación Básico

Une dos líneas con un corte recto en la esquina (chaflán).

STRETCH S Modificación Intermedio

Estira o comprime objetos moviendo vértices dentro de una selección cruzada.

EXPLODE X Edición Básico

Descompone un bloque, polilínea o array en sus objetos individuales.

JOIN J Modificación Intermedio

Une líneas o arcos contiguos en un solo objeto (lo opuesto a EXPLODE).

BREAK BR Modificación Intermedio

Rompe un objeto en dos partes o elimina un segmento entre dos puntos.

MATCHPROP MA Modificación Intermedio

Copia propiedades (capa, color, tipo de línea) de un objeto a otro.

OSNAP F3 Precisión Básico

Alterna las referencias a objetos: extremo, medio, centro, intersección, etc.

LAYER LA Capas Básico

Abre el Administrador de capas para crear, editar y gestionar capas.

LAYISO Capas Intermedio

Aísla la capa de un objeto seleccionado, ocultando todas las demás.

LAYUNISO Capas Intermedio

Restaura el estado de visibilidad de capas anterior a LAYISO.

BLOCK Bloques Básico

Crea un bloque a partir de objetos seleccionados, definiendo nombre y punto base.

INSERT I Bloques Básico

Inserta un bloque existente en el dibujo actual.

BEDIT Bloques Intermedio

Abre el editor de bloques para modificar el contenido de un bloque definido.

DIMLINEAR Acotación Básico

Crea una cota lineal horizontal o vertical entre dos puntos.

DIMALIGNED Acotación Básico

Cota paralela a una línea inclinada.

DIM DIM Acotación Intermedio

Cota inteligente que detecta automáticamente el tipo según el objeto seleccionado.

DIMSTYLE D Acotación Intermedio

Administra estilos de cota: tamaño de texto, flechas, unidades y precisión.

TEXT DT Texto Básico

Texto de una sola línea, útil para etiquetas cortas y títulos.

MTEXT T Texto Básico

Texto multilínea con formato rich text dentro de un cuadro definido.

STYLE ST Texto Intermedio

Define fuente, altura y estilo por defecto para los textos del dibujo.

TABLE TB Texto Intermedio

Inserta tablas de datos con filas y columnas (cuadro de acabados, áreas, etc.).

HATCH H Edición Básico

Rellena un área cerrada con un patrón de sombreado (rayado, sólido, material).

PEDIT PE Edición Intermedio

Edita polilíneas: unir segmentos, abrir/cerrar, suavizar o asignar ancho.

PROPERTIES Ctrl+1 Edición Básico

Abre la paleta de propiedades para ver y editar atributos de objetos seleccionados.

BOX 3D Avanzado

Crea un sólido rectangular definido por largo, ancho y alto.

CYLINDER 3D Avanzado

Crea un sólido cilíndrico por radio de base y altura.

EXTRUDE EXT 3D Avanzado

Empuja un perfil 2D cerrado en línea recta para crear un sólido.

REVOLVE REV 3D Avanzado

Gira un perfil 2D alrededor de un eje para generar un sólido de revolución.

SWEEP 3D Avanzado

Desplaza un perfil a lo largo de una trayectoria curva (tubería, moldura).

LOFT 3D Avanzado

Genera una forma suave conectando dos o más perfiles entre sí (solevación).

UNION 3D Avanzado

Fusiona dos o más sólidos en un solo objeto (unión booleana).

SUBTRACT SU 3D Avanzado

Resta el volumen de un sólido de otro (perforar, recortar volumen).

INTERSECT IN 3D Avanzado

Conserva únicamente el volumen común entre dos o más sólidos.

3DORBIT 3D Avanzado

Órbita libre alrededor del modelo 3D para visualizar desde cualquier ángulo.

RENDER RR 3D Avanzado

Genera una imagen renderizada del modelo 3D con materiales, luces y cámara.

DIST DI Consulta Básico

Mide la distancia y ángulo entre dos puntos del dibujo.

LIST LI Consulta Básico

Muestra propiedades detalladas de un objeto seleccionado (capa, tipo, área, longitud).

AREA AA Consulta Intermedio

Calcula el área y perímetro de un polígono o selección de puntos.

MEASURE ME Consulta Intermedio

Coloca puntos o bloques a lo largo de un objeto a intervalos iguales.

ZOOM Z Consulta Básico

Amplía o reduce la vista del área de dibujo (opciones: E, W, P, All).

PURGE PU Consulta Intermedio

Elimina elementos no utilizados del archivo: capas, bloques, estilos, tipos de línea.

AUDIT Consulta Intermedio

Detecta y corrige errores internos del archivo DWG.

WBLOCK W Consulta Intermedio

Exporta objetos o el dibujo completo a un archivo DWG separado.
