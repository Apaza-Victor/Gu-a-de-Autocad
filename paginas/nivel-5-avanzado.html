Diccionario de comandos

1Personalización de la interfaz (CUI)

El comando CUI (Customize User Interface) abre un diálogo donde puedes modificar casi todo el entorno visual de AutoCAD: barras de herramientas, menús, teclas de acceso rápido y cintas de opciones.

Qué puedes personalizar

  • Pestañas y paneles de la cinta: crear tu propia pestaña con los comandos que más usas.
  • Barras de herramientas rápidas: agregar iconos de uso frecuente en la parte superior.
  • Atajos de teclado: asignar combinaciones personalizadas (por ejemplo, Ctrl+Shift+M para MATRIZ).
  • Menús contextuales: agregar opciones al clic derecho según el tipo de objeto.
Consejo Antes de modificar la interfaz, exporta una copia de tu configuración actual desde el propio diálogo CUI, por si necesitas restaurar algo después.

2AutoLISP y scripts básicos

AutoLISP es un lenguaje de programación integrado en AutoCAD que permite automatizar tareas repetitivas, crear comandos personalizados y extender las capacidades del programa.

ConceptoEjemplo
Cargar un archivo LISPEscribir APPLOAD en la línea de comandos
Función básica(command "LINE" pt1 pt2 "")
Obtener un punto del usuario(setq pt (getpoint "Selecciona punto:"))
Obtener un valor numérico(setq d (getdist "Distancia:"))

También existen los scripts simples (archivos .SCR) que son secuencias de comandos escritos línea por línea, útiles para ejecutar rutinas de dibujo o configuración sin programar.

Ejemplo de script AutoLISP

Este script dibuja un rectángulo de dimensiones variables que el usuario define:

AutoLISP 
;; Dibuja un rectángulo con dimensiones del usuario
(defun c:RECTMI ()
  (setq pt (getpoint "Punto base: "))
  (setq w (getdist pt "Ancho: "))
  (setq h (getdist pt "Alto: "))
  (command "RECTANG" pt
    (list (+ (car pt) w) (+ (cadr pt) h))
  )
  (princ)
)
Para probarlo Copia el código en un archivo rectmi.lisp, carga con APPLOAD y escribe RECTMI en la línea de comandos.

3Estándares CAD profesionales

En equipos de trabajo profesional, todos los dibujantes deben seguir las mismas reglas para que los archivos sean consistentes y interoperables. Los más conocidos son:

EstándarUso típicoPaíses
ISO (Organización Internacional de Normalización)Planos arquitectónicos, mecánicos e industrialesMundial (especialmente Europa y Latinoamérica)
ANSI (Instituto Nacional Estadounidense)Ingeniería mecánica y estructuralEstados Unidos
DIN (Instituto Alemán de Normalización)Arquitectura, ingeniería civil, mobiliarioAlemania, Europa central
ABNT (Asociación Brasileña de Normas)Arquitectura e ingeniería civilBrasil

Un archivo de estándar CAD (.DWS) verifica automáticamente que tu dibujo cumpla con la nomenclatura de capas, estilos de texto y de cota requeridos por el proyecto.

4Buenas prácticas de dibujo profesional

  • Nomenclatura de capas: usa un sistema consistente, por ejemplo ARQ-Muros, EST-Columnas, INST-Tuberia, donde el prefijo indica el disciplina.
  • Dibuja a escala 1:1 siempre en el espacio modelo; la escala se aplica solo en el layout.
  • Usa bloques para elementos repetidos (mobiliario, símbolos, accesorios).
  • No dibujes en la capa 0 para elementos finales; úsala solo para crear bloques.
  • Verifica ortogonalidad con ORTO y OSNAP antes de imprimir.
  • Guarda con frecuencia y usa versiones (SAVEAS) en hitos importantes del proyecto.
  • Externaliza referencias (Xref) en proyectos colaborativos para evitar duplicación.
Error común No uses colores directamente sobre objetos para "diferenciar" elementos. Siempre trabaja desde la capa: el color, tipo de línea y grosor deben definirse en la capa, no en el objeto.

6Optimización de archivos y solución de errores

Reducir el tamaño del archivo

  • PURGE: elimina capas, bloques, estilos y tipos de línea no utilizados.
  • AUDIT: detecta y corrige errores internos del archivo.
  • SCALELISTEDIT: elimina escalas de lista no usadas (causa común de aumento de tamaño).
  • DELTA: elimina datos de versiones anteriores guardadas en el archivo.

Errores comunes y soluciones

ProblemaSolución
El archivo pesa demasiadoPURGE + AUDIT + WBLOCK (exportar todo a un archivo limpio)
Las cotas se ven desproporcionadasVerificar que la escala de la ventana gráfica coincida con la escala de anotación
El hatch no se aplicaEl contorno no está cerrado; usar BOUNDARY para detectar fugas
Los textos no se imprimenVerificar que la capa de textos no esté en "No imprimir"
La Xref no se actualizaUsar XREF → pestaña "Lista" → clic derecho → "Recargar"
Flujo de limpieza recomendado Antes de entregar un plano: AUDIT → PURGE → SAVEAS a un archivo nuevo → verificar impresión en vista previa.

7Dynamo para AutoCAD

Dynamo es un entorno de programación visual que se ejecuta dentro de AutoCAD. Permite crear flujos de trabajo repetitivos arrastrando nodos en un lienzo gráfico, sin escribir código.

¿Para qué sirve Dynamo en AutoCAD?

  • Generar geometría paramétrica: crear múltiples variaciones de un diseño cambiando parámetros de entrada.
  • Procesamiento por lotes: renombrar capas, exportar bloques, modificar propiedades de cientos de objetos a la vez.
  • Automatización de planos: generar vistas de planta, fachada y corte a partir de un modelo 3D.
  • Diseño generativo: explorar cientos de soluciones que cumplen restricciones específicas.

Cómo acceder

  1. Escribe DYNAMO para abrir el editor visual.
  2. En el panel de librerías, busca nodos de AutoCAD (como Curve.PointAtParameter, Solid.ByRevolution, etc.).
  3. Conecta nodos con cables para definir el flujo de datos.
  4. Ejecuta con Ctrl+Enter o el botón Run.
Aprendizaje Dynamo tiene una comunidad activa con scripts compartidos en dynpackage.com. Empieza descargando paquetes como Clockwork o Bakery que amplían mucho las capacidades nativas.

8Automatización con Python (pyautocad)

Si prefieres código textual en lugar de nodos visuales, Python es una alternativa moderna a AutoLISP para automatizar AutoCAD.

La librería pyautocad

pyautocad es una librería de Python que se conecta a AutoCAD mediante COM. Permite crear, leer y modificar dibujos programáticamente.

Python 
from pyautocad import Autocad

acad = Autocad()  # Conecta a AutoCAD abierto

# Crear una línea desde (0,0,0) hasta (100,50,0)
p1 = acad.Point3D(0, 0, 0)
p2 = acad.Point3D(100, 50, 0)
line = acad.model.AddLine(p1, p2)

# Crear un círculo
center = acad.Point3D(50, 25, 0)
circle = acad.model.AddCircle(center, 25)

print(f"Línea creada: {line}")
print(f"Círculo creado: {circle}")

Cuándo usar Python vs. AutoLISP

CriterioAutoLISPPython (pyautocad)
Curva de aprendizajeMás empírico, sintaxis antiguaSintaxis moderna, más recursos de aprendizaje
BibliotecasSolo las nativas de AutoCADTodas las librerías de Python (numpy, pandas, etc.)
Uso en la industriaMuy extendido en empresas CADCreciente, más común en entornos BIM y data-driven
CompatibilidadSolo AutoCADAutoCAD + Revit + Civil 3D

9AutoCAD y BIM

BIM (Building Information Modeling) es el flujo de trabajo que conecta arquitectura, ingeniería y construcción en un modelo digital compartido. AutoCAD no es un software BIM nativo, pero se integra con el ecosistema BIM de Autodesk.

Módulos verticales de AutoCAD con BIM

MóduloUso
AutoCAD ArchitectureDibujo arquitectónico con objetos inteligentes (muros, puertas, ventanas) que generan datos BIM.
AutoCAD MEPDiseño de instalaciones mecánicas, eléctricas y sanitarias con componentes paramétricos.
AutoCAD Civil 3DIngeniería civil: terreno, alineamientos, perfiles, cunetas y redes.
AutoCAD Plant 3DDiseño de plantas industriales y tuberías isométricas.
Tendencia La industria está migrando de AutoCAD 2D puro a Revit y Civil 3D para proyectos nuevos. AutoCAD sigue siendo esencial para proyectos existentes, planos legados y trabajos donde el modelo BIM no es obligatorio.

10Interoperabilidad CAD-BIM

En un proyecto real, no todo el mundo usa el mismo programa. AutoCAD debe comunicarse con Revit, SketchUp, Civil 3D, softwares de cálculo y más.

Formatos de intercambio

FormatoUso principalLimitaciones
.DWGFormato nativo Autodesk. Compatible entre AutoCAD, Revit, Civil 3D.No es universal; algunos softwares no lo leen.
.DXFFormato de texto plano para intercambio CAD universal.Puede perder algunas propiedades específicas de AutoCAD.
.IFCFormato abierto BIM. Estándar para compartir modelos entre Revit, ArchiCAD, Tekla.No preserva todas las configuraciones de cada software.
.SATIntercambio de sólidos 3D ACIS entre programas CAD.Solo geometría sólida, sin capas ni estilos.
.STEP / .STPEstándar de la industria para piezas mecánicas y CAD 3D.Pesado, pierde información de dibujo 2D.
.IGESIntercambio de superficies y curvas NURBS entre CAD y CAM.En desuso gradual a favor de STEP.
.PDFRevisión y distribución sin capacidad de edición.No es editable en CAD (salvo importación de geometría).

Herramientas de conversión

  • IMPORT / EXPORT: comandos nativos de AutoCAD para convertir entre formatos.
  • Navisworks: integra modelos de Revit, AutoCAD y SketchUp para revisión de coordinación.
  • Autodesk Viewer: visor en línea que abre DWG, RVT, IFC y otros formatos sin instalar nada.
Consejo profesional Cuando compartas un plano con alguien que usa un software diferente, ofrece siempre dos versiones: una en .DWG (si el receptor puede leerlo) y otra en .DXF o .PDF como respaldo universal.
