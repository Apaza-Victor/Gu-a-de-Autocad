Añadir una textura de imagen a un bloque combina dos mundos: la precisión vectorial del dibujo y la riqueza visual de una foto. Sirve para hacer ver "madera", "hormigón" o "césped" a mópedir muebles y fachadas, tanto en 2D como en render.

1. Insertar una imagen de textura en el dibujo

La textura se adjunta como imagen externa y luego se recorta y orienta sobre el bloque:

1

Adjunta la imagen

Escribe IMAGEATTACH (IM) para adjuntar la textura. Elige el archivo de imagen (JPG o PNG). AutoCAD la coloca con un punto de inserción y una escala.

2

Colócala sobre el bloque

Usa MOVE y SCALE para superponer la imagen sobre la silueta del bloque. La imagen se recorta con IMAGECLIP.

3

Recorta el exceso

Con la imagen seleccionada, escribe IMAGECLIP y dibuja un rectángulo que deje solo la parte útil (por ejemplo el tablero de la mesa).

4

Transparencia para fondos

Si la imagen tiene fondo, usa IMAGEFRAME = 2 (o 0) para ocultar el marco al trazar, y TRANSPARENCY para imágenes PNG con canal alfa.

2. Hacer que la textura forme parte del bloque

Para que la imagen viaje con el bloque (por ejemplo, al insertar el bloque en otro archivo):

1

Crea el bloque con todo

Ejecuta BLOCK (B), nómbralo y selecciona los vectores más la imagen. Así la textura queda dentro de la definición.

2

Aviso de dependencias

Si la imagen se borra o se mueve de carpeta, el bloque mostrará "imagen no encontrada". Para viajar seguro, guarda la imagen junto al archivo o usa el asistente ETRANSMIT.

3. Texturas de material para render (nivel 4)

Para que el bloque se vea con material realista en vistas 3D y render:

  • Usa la pestaña Render → Materiales (o MATERIALS) y crea un material nuevo.
  • En "Imagen de textura" adjunta el mismo archivo de imagen.
  • Arrastra el material sobre la cara del objeto o asígnalo por capa.
  • Aplica SOLIDEDIT → "Cara" → "Material" para pegarlo a una cara concreta.

4. Texturas desde bloques dinámicos personalizados

También puedes usar bloques 2D con relleno: dentro del Editor de bloques (BEDIT), crea un sombreado solido (HATCH → tipo Sólido) con color claro y encima superpone la imagen recortada. El resultado se comporta como una lámina: se mueve, rota y escala con el bloque.

Tip En fachadas, en vez de dibujar cada ladrillo, adjunta una textura de ladrillo proporcionada (que se repita sin costuras) con MATERIALMAP → casilla "Ajustar". Ganarás horas y el render se verá mucho más real.
