6Publicación por lotes (PUBLISH)

Cuando el proyecto tiene varios layouts o varios archivos, imprimir uno a uno es lento y propenso a olvidos. PUBLISH (PUBLISH, Ctrl+P con la lista de hojas) crea una lista de hojas con todos los layouts y archivos que quieres y genera de una sola vez el PDF completo, los plotters o los archivos DWF.

Idea clave Antes de publicar, cada layout debe tener su configuración de página correcta (papel, escala, estilo de trazado). PUBLISH solo ejecuta esas configuraciones: si una hoja está mal definida, sale mal.

Qué incluye la lista de hojas

ElementoQué hace
Layouts del archivo actualCada pestaña de presentación se añade como hoja independiente.
Otros archivos .DWGCon el botón Agregar hojas añades archivos completos (todas sus layouts).
ModeloLa pestaña Modelo se imprime con su configuración de espacio modelo si la marcas.
Conjuntos de planosSe pueden publicar todas las láminas de un Sheet Set en bloque.

Publicar a PDF paso a paso

1

Abre el diálogo

Fichero → Publicar (o escribe PUBLICAR (en inglés: PUBLISH)).

2

Completa la lista

Marca los layouts a publicar o usa Agregar hojas / Importar para traer layouts de otros archivos del proyecto.

3

Elige el destino

En Lista de plotters selecciona un destino: DWG To PDF.pc3, PDF, plotter física o DWF.

4

Configura el PDF

Activa "Publicar hojas en orden inverso" si tu gráfica lo requiere y define Opciones de PDF: capas (capa por hoja), calidad y marcado de impresión.

5

Publica

Pulsa Publicar, guarda el archivo .DWF de cola (opcional) y revisa el resultado: un único PDF con todas las hojas del proyecto.

Error común Publicar con hojas que no tienen configuración de página definida. Revisa cada layout con PREPARARPÁG (en inglés: PAGESETUP) antes de publicar; si no, "Hojas No insertadas" producirá un PDF con blancos o escalas equivocadas.

Mini ejercicio: publica tu proyecto de prueba

1

Prepara dos layouts

Configura dos presentaciones (Planta 1:50 y Detalle 1:20) con su PREPARARPÁG (en inglés: PAGESETUP) y estilo de trazado monochrome.

2

Publícalas

Con PUBLICAR (en inglés: PUBLISH) añade ambas hojas y publica a DWG To PDF.pc3.

3

Reordena

En la lista, arrastra el Detalle antes de la Planta y vuelve a publicar: el orden del PDF cambia sin tocar los dibujos.
