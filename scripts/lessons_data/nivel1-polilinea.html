Una polilínea es una secuencia de segmentos (rectos o curvos) que funcionan como un único objeto. A diferencia de dibujar varias líneas sueltas, la polilínea se selecciona, se edita y se usa como contorno de sombreado o de extrusión con mucha mayor facilidad.

1. Ejecutar el comando

CómoQué escribirAtajo
Barra de comandosPOLILÍNEA (en inglés: PLINE)PL
Cinta → Inicio → DibujoIcono de polilíneaClic

2. Cómo se usa

1

Primer segmento

POLILÍNEA (en inglés: PLINE) → clic en el punto inicial → clic o distancia para el final del tramo recto.

2

Cambia a arco

Teclea A (Arco) para dibujar segmentos curvos; con L vuelves a rectas. También puedes dar ancho a los trazos con la opción G (Grosor).

3

Cierra la figura

Con C cierras y terminas; esa ventaja permite que el sombreado o la extrusión reconozcan el contorno sin huecos.

3. Mini ejercicio

1

Un perfil cerrado

PL → clic → 4 tramos rectos dibujando un rectángulo de 150×80 → opción C para cerrar.

2

Compruébalo

Haz clic sobre cualquier tramo: se selecciona todo el contorno. Luego rellénalo con SOMBREADO (en inglés: HATCH) y verás que el contorno se reconoce al instante.

Error común Creer que línea y polilínea son intercambiables. Si dibujas un muro con L (líneas sueltas), el sombreado, el grosor y la edición de vértices se complican; con polilínea todo es más simple. Regla: dibuja "compuestos" siempre con PL.
