Un plano sin texto no es un plano: necesita títulos, notas, rótulos y dimensiones. AutoCAD tiene dos herramientas: TEXTO (en inglés: TEXT, una línea simple) y TEXTOM (en inglés: MTEXT, textos enriquecidos de varias líneas con formato). Saber cuándo usar cada una ya es media batalla.

1. Comandos

ParaComandoAtajo
Una línea cortaTEXTO (en inglés: TEXT)TEX
Varias líneas / notasTEXTOM (en inglés: MTEXT)T o MT

2. Cómo se usa

1

Texto simple (TEXT)

TEXTO (en inglés: TEXT) → clic donde va el texto → altura (ej. 2.5) → ángulo (normalmente 0) → escribe y pulsa Enter. Para una línea o rótulo corto es perfecto.

2

Texto enriquecido (MTEXT)

TEXTOM (en inglés: MTEXT) → arrastra un cuadro (ancho del párrafo) → escribe el contenido. En la cinta editable el formato (negrita, tamaño, interlineado, alineación). Termina con OK fuera del cuadro.

3

Editar

Doble clic sobre cualquier texto lo abre para editar sin perder el formato. Con ESTILO (en inglés: STYLE) defines la fuente/altura por defecto.

3. Mini ejercicio

1

Un rótulo de plano

TEXTO (en inglés: TEXT) → clic abajo del plano → escribe "Planta de cimentación". Prueba a cambiarle la altura si sale pequeño.

2

Una nota de proyecto

TEXTOM (en inglés: MTEXT) → dibuja el cuadro → escribe dos líneas: "NOTA: el hormigón será HA-25/P/20/IIa. Todas las cotas en cm." Usa negrita en la primera línea.

Error común Poner textos "flotantes" en medio del plano sin capa ni estilo de texto definido. Crea una capa Cotas/Texto y un estilo de texto estándar; todo lo escrito subirá ordenado y editable cuando el equipo lo necesite.
