HerramientaComandoUso
Texto de una líneaTEXTO (en inglés: TEXT)Etiquetas cortas, títulos de una sola línea.
Texto multilíneaTEXTM (en inglés: MTEXT)Párrafos con formato, dentro de un cuadro de ancho definido.
Estilo de textoESTILO (en inglés: STYLE)Define fuente, altura y ancho por defecto para los textos.
TablaTABLA (en inglés: TABLE)Inserta cuadros de datos (ej. cuadro de acabados o de áreas).
Cuidado Evita escribir el mismo texto varias veces si el valor puede cambiar (como un área o un total). Extráelo desde una tabla o un atributo de bloque para que se actualice automáticamente.

Texto de una línea frente a texto multilínea

TEXTO (en inglés: TEXT) crea líneas sueltas; TEXTM (en inglés: MTEXT) crea un párrafo dentro de un rectángulo. Regla práctica: etiquetas cortas con TEXT, notas y párrafos con MTEXT. El multilínea permite columnas, listas, símbolos, subrayados y fuentes mixtas en un solo objeto fácil de mover.

  • Estilo con STYLE: define la fuente y la altura; el texto hereda el estilo. Nunca cambies la fuente objeto a objeto.
  • Revisión de ortografía: ORTOGRAFÍA (en inglés: SPELL) (SP) revisa todo el dibujo.
  • Tablas: TABLA (en inglés: TABLE) crea cuadros de datos que se rellenan y expanden; ideal para cuadros de acabados o de áreas.
  • Campos: dentro de MTEXT, clic derecho → Insertar campo → Objeto → área de polígono: el valor se actualiza solo (ver ejercicio).
  • Anotativo: marca el estilo como anotativo si el texto debe escalarse con el layout (Nivel 3).
Error común Aplanar textos a líneas (TXTEXP o similar). En planos editables los textos deben seguir siendo texto; solo "aplanar" cuando el archivo ya no se va a modificar.

Mini ejercicio: cuadro de áreas que se actualiza solo

1

Crea un campo de área

Dibuja un rectángulo de 300 x 200 y, dentro de un MTEXT, inserta el campo Objeto → área de polígono seleccionando el rectángulo.

2

Cambia la geometría

Mueve una esquina del rectángulo y escribe REGENERAR (en inglés: REGEN) (RE): el campo se actualiza a la nueva área.
