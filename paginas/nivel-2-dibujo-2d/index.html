Responde las 5 preguntas y comprueba cuánto has retenido de este nivel. Cada respuesta muestra una explicación al instante.

1) ¿Cuál es el atajo de MATCHPROP y qué hace?

MATCHPROP se escribe con el atajo MA y copia propiedades (capa, color, tipo de línea, texto…) entre objetos.

2) ¿Cuál es la diferencia principal entre PEDIT y JOIN?

JOIN es la vía rápida para unir; PEDIT edita la polilínea con opciones como Join, Close, Edit vertex, Width y Spline.

3) ¿Cuándo conviene usar una spline en lugar de un arco?

El arco (o FILLET) es para radio constante; la spline modela curvas libres que no siguen un radio único.

4) ¿Qué hace el comando EXPLODE?

EXPLODE (X) rompe bloques y polilíneas en sus piezas sueltas. Úsalo con cuidado: no se puede "des-explosionar".

5) ¿Por qué es correcto dibujar con color y tipo de línea ByLayer?

Con ByLayer el objeto obedece a su capa: cambias el color o el estado de la capa y se actualiza todo el dibujo a la vez.
