1 Herramientas de dibujo

Son los comandos que crean geometría nueva. Todos aceptan coordenadas exactas (ver Nivel 1) además de clics con el mouse.

HerramientaComandoAtajoUso
LíneaLINELSegmentos rectos entre puntos.
PolilíneaPLINEPLSerie de segmentos y arcos unidos como un solo objeto.
CírculoCIRCLECPor centro-radio, dos o tres puntos, entre otras opciones.
ArcoARCATramo curvo definido por 3 puntos, centro-inicio-fin, entre otras.
RectánguloRECTANGRECRectángulo a partir de dos esquinas opuestas.
PolígonoPOLYGONPOLPolígono regular inscrito o circunscrito en un círculo.
ElipseELLIPSEELCurva elíptica por eje mayor/menor o por centro.
SplineSPLINESPLCurva suave que pasa por una serie de puntos de control.

LINE — Líneas rectas entre puntos
Línea (LINE)

Dibuja segmentos rectos. Usa ORTO para líneas perfectamente horizontales o verticales.

PLINE — Polilíneas combinadas
Polilínea (PLINE)

Segmentos rectos y curvos en un solo objeto. Ideal para contornos cerrados.

CIRCLE — Círculos por centro-radio
Círculo (CIRCLE)

Crear círculos por centro y radio, dos puntos o tres puntos.

RECTANG — Rectángulos rápidos
Rectángulo (RECTANG)

Define dos esquinas opuestas para crear el rectángulo.

OFFSET — Copias paralelas
Desfase (OFFSET)

Crea copias paralelas a distancia exacta. Fundamental para muros.

TRIM — Recorte preciso
Recortar (TRIM)

Elimina la parte de un objeto que sobrepasa un límite de referencia.

Buena práctica Prefiere PLINE sobre LINE cuando dibujes un contorno cerrado (como un muro o una pieza): al ser un solo objeto, es más fácil de seleccionar, editar y aplicarle sombreado después.

2 Herramientas de modificación

Permiten transformar objetos ya dibujados sin volver a trazarlos desde cero.

HerramientaComandoAtajoUso
MoverMOVEMTraslada objetos de un punto base a un punto destino.
CopiarCOPYCOIgual que mover, pero conserva el original.
RotarROTATEROGira objetos un ángulo respecto a un punto base.
EscalarSCALESCAumenta o reduce el tamaño respecto a un punto base.
RecortarTRIMTRElimina la parte de un objeto que sobrepasa un límite.
AlargarEXTENDEXExtiende un objeto hasta tocar un límite de referencia.
DesfaseOFFSETOCopia paralela a una distancia exacta (ideal para muros).
SimetríaMIRRORMIRefleja objetos respecto a un eje.
MatrizARRAYARRepite objetos en filas/columnas, en círculo o a lo largo de una ruta.
EmpalmeFILLETFUne dos líneas con un arco de radio definido.
ChaflánCHAMFERCHAUne dos líneas con un corte recto en la esquina.
Flujo típico Un muro en planta suele dibujarse así: PLINE para el eje → OFFSET para dar el espesor → TRIM para limpiar las esquinas → FILLET con radio 0 para unir vértices sueltos.

3 Precisión: referencias, rastreo y cuadrícula

AutoCAD ofrece ayudas de precisión que se activan/desactivan desde la barra de estado o con teclas de función, para hacer clic exactamente donde se necesita, sin calcular coordenadas a mano.

AyudaTeclaQué hace
Referencia a objetos (OSNAP)F3Engancha el cursor a puntos exactos: extremo, medio, centro, intersección, etc.
Rastreo polarF10Muestra líneas guía en ángulos predefinidos (0°, 45°, 90°…).
Modo ORTOF8Restringe el cursor a líneas perfectamente horizontales o verticales.
Cuadrícula / GridF7Muestra una retícula visual de referencia en el área de dibujo.
Forzar cursor (SNAP)F9Obliga al cursor a "saltar" entre puntos de una cuadrícula fija.

4 Capas (Layers)

Una capa es un "acetato" transparente donde se agrupan objetos con propiedades comunes. Se administran desde el Administrador de propiedades de capas (comando LAYER / LA).

Propiedades que puede tener cada capa

  • Color: identifica visualmente la capa y, si se imprime por color, puede controlar el grosor de línea.
  • Tipo de línea: continua, discontinua, de eje, punteada, etc. (se cargan con el comando LINETYPE).
  • Grosor de línea: define el espesor con que se imprime esa capa.
  • Estado: activada/desactivada, inmovilizada, congelada, sin imprimir.
Regla de oro Dibuja siempre en la capa correspondiente al elemento (muros en "Muros", cotas en "Cotas") y no cambies el color manualmente objeto por objeto. Así, si necesitas ocultar todas las cotas, basta con apagar una sola capa.

5 Bloques y atributos

Un bloque es un conjunto de objetos agrupados bajo un solo nombre, reutilizable en el mismo dibujo o en otros (una puerta, una silla, un símbolo eléctrico).

AcciónComando
Crear un bloque a partir de objetos seleccionadosBLOCK
Insertar un bloque existenteINSERT
Editar el contenido de un bloqueBEDIT
Descomponer un bloque en objetos sueltosEXPLODE

Un bloque puede incluir atributos: campos de texto editables asociados al bloque, útiles para etiquetar (por ejemplo, el número de una habitación o el código de una pieza) y luego extraerlos en una tabla.

6 Acotación (dimensiones)

Acotar es indicar medidas reales sobre el dibujo. AutoCAD calcula automáticamente la distancia entre los puntos que selecciones, siempre que el dibujo esté hecho a escala 1:1.

Tipo de cotaComandoUso
LinealDIMLINEARDistancia horizontal o vertical entre dos puntos.
AlineadaDIMALIGNEDDistancia paralela a una línea inclinada.
AngularDIMANGULARMide el ángulo entre dos líneas.
Radio / DiámetroDIMRADIUSMide arcos y círculos.
Cota rápidaDIMDetecta automáticamente el tipo de cota según el objeto.

Los estilos de cota (comando DIMSTYLE) controlan el tamaño de texto, flechas, unidades y precisión decimal de todas las cotas de ese estilo a la vez.

7 Texto, estilos de texto y tablas

HerramientaComandoUso
Texto de una líneaTEXTEtiquetas cortas, títulos de una sola línea.
Texto multilíneaMTEXTPárrafos con formato, dentro de un cuadro de ancho definido.
Estilo de textoSTYLEDefine fuente, altura y ancho por defecto para los textos.
TablaTABLEInserta cuadros de datos (ej. cuadro de acabados o de áreas).
Cuidado Evita escribir el mismo texto varias veces si el valor puede cambiar (como un área o un total). Extráelo desde una tabla o un atributo de bloque para que se actualice automáticamente.

8 Sombreado y rellenos (Hatch)

El comando HATCH (H) rellena un área cerrada con un patrón: rayado de concreto, ladrillo, tierra, agua, etc. Requiere que el contorno esté completamente cerrado; si queda un espacio abierto, AutoCAD no podrá aplicar el relleno.

  • Patrón: selecciona el motivo (líneas, puntos, sólido, patrones prediseñados por material).
  • Escala: ajusta el tamaño del patrón según la escala del plano.
  • Ángulo: rota el patrón, útil para diferenciar materiales similares.
  • Asociatividad: si el hatch es asociativo, se actualiza automáticamente al modificar el contorno.

9 Selección de objetos

Antes de mover, copiar, borrar o modificar cualquier cosa, necesitas seleccionar los objetos correctos. AutoCAD ofrece varios métodos de selección que conviene dominar.

MétodoCómo se haceQué selecciona
Clic directoHacer clic sobre un objetoEl objeto tocado por el cursor.
Ventana (de izq. a der.)Arrastrar el mouse de izquierda a derechaSolo los objetos completamente dentro del rectángulo (borde azul sólido).
Selección cruzante (de der. a izq.)Arrastrar el mouse de derecha a izquierdaCualquier objeto que toque o cruce el rectángulo (borde verde punteado).
Selección por nombreEscribir SELECT y el nombre del conjunto guardadoUn grupo de objetos previamente guardado con GROUP.
FiltrosEscribir FILTERSelecciona objetos por propiedades (capa, color, tipo, longitud…).
Selección anteriorEscribir P como opción de selecciónRepite la selección anterior.
Atajo de precisión Si seleccionas de más, mantén Shift y haz clic sobre el objeto que quieras deseleccionar. También puedes escribir R (Remove) para entrar en modo deselección.

10 Tipos de línea

Un tipo de línea controla cómo se ve un objeto: continua, discontinua, de eje, punteada, etc. Se asigna por capa o directamente al objeto.

Tipos más usados

TipoNombre estándarUso típico
ContinuaContinuousMuros, contornos, cotas.
DiscontinuaDASHEDLíneas ocultas, bordes no visibles.
De ejeCENTEREjes de simetría, ejes de ventanas.
PunteadaDOTTEDLíneas de referencia, proyecciones.
FantasmasPHANTOMMovimientos, posiciones alternativas.

Cargar y asignar tipos de línea

Los tipos de línea no están cargados por defecto. Se cargan con el comando LINETYPE (o LT):

  1. Escribe LINETYPE y presiona Enter.
  2. Haz clic en "Cargar" (Load) y busca el tipo que necesitas en el archivo acad.lin.
  3. Selecciona y acepta. Ahora el tipo aparecerá en la lista de la capa correspondiente.

La escala del tipo de línea se controla con la variable LTSCALE. Si las líneas discontinuas se ven continuas, probablemente necesitas ajustar esta escala.

11 Puntos y división

Los comandos DIVIDE y MEASURE colocan puntos o bloques a lo largo de un objeto, algo que se usa mucho para distribuir elementos de forma regular (como pilares, barras de acero o postes de luminarias).

ComandoQué haceEjemplo práctico
DIVIDEDivide un objeto en un número igual de segmentos y coloca puntos o un bloque en cada división.Dividir una línea de 20 m en 5 partes = puntos cada 4 m.
MEASUREColoca puntos o bloques a lo largo de un objeto a una distancia fija que tú defines.Colocar postes cada 5 m a lo largo de una polilínea.
PDMODEControla la apariencia visual de los puntos (círculo, cruz, X, etc.).PDMODE = 2 muestra una X en cada punto.
PDSIZEControla el tamaño de los puntos en pantalla.Ajustar según la escala del dibujo.
Consejo Si los puntos no se ven, cambia PDMODE a un valor como 2 o 3. Los puntos aparecen como una X o un círculo visible sobre el objeto.

12 Geometría auxiliar

Las líneas de construcción son objetos temporales que ayudan a ubicar puntos y alinear elementos, pero que no se imprimen ni forman parte del plano final.

ComandoAtajoQué hace
XLINEXLLínea infinita en una dirección (horizontal, vertical o angular). Ideal para trazar ejes de referencia.
RAY—Semitrayectoria que nace de un punto y se extiende indefinidamente en una dirección.
LINELLínea finita. Úsala con la opción "Inextendible" si quieres segmentos temporales.

Buenas prácticas con geometría auxiliar

  • Dibuja toda la geometría auxiliar en una capa dedicada (por ejemplo, "Auxiliar") con un color visible pero que no se imprima.
  • Usa XLINE para establecer los ejes principales de un plano antes de dibujar muros.
  • Cuando el plano esté terminado, congela o apaga la capa auxiliar con LAYISO para ver el resultado limpio.
Flujo típico XLINE (ejes verticales y horizontales) → OFFSET (dar espesor a muros) → TRIM (recortar intersecciones) → resultado final.
