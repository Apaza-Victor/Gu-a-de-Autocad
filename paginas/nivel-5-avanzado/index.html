Ejemplos del nivel

Automatización Flujo AutoLISP

Modifica barras de herramientas, menús, teclas rápidas y paneles arrastrando comandos.

Poder real Con AutoLISP puedes crear comandos personalizados que ejecuten secuencias complejas con un solo atajo.

Interfaz Personalización CUI

CUI
Tip Escribe CUI para abrir el editor. Crea un grupo de comandos personalizados para tu flujo de trabajo diario.

Mantenimiento PURGE y AUDIT

PURGE elimina capas, bloques y estilos no usados. AUDIT corrige errores internos del DWG.

Tip Ejecuta PURGE periódicamente para reducir tamaño. AUDIT después de un cierre inesperado o si el archivo falla.

CAD-BIM Flujo interoperabilidad

Lleva tu plano de AutoCAD a un flujo BIM: exporta a IFC o vincula el DWG como referencia en Revit para coordinar arquitectura, estructura e instalaciones.

Tendencia El futuro del CAD profesional pasa por la integración BIM. AutoCAD sigue siendo el punto de partida sólido.

Responde las 5 preguntas para comprobar lo aprendido. Pulsa la opción correcta y aparecerá la explicación con tu puntuación.

1. ¿Qué necesita un bloque para tener un grip de estiramiento?

El estiramiento combina un parámetro (que genera el grip) y una acción que aplica ese cambio a la geometría seleccionada.

2. ¿Qué diferencia hay entre restricciones geométricas y de cota?

GEOMCONSTRAINT controla la forma y la posición relativa; DIMCONSTRAINT controla tamaños y distancias numéricas.

3. ¿Para qué sirve un archivo de estándares .DWS?

El .DWS contiene las definiciones oficiales; CHECKSTANDARDS compara tu dibujo contra él y corrige las infracciones.

4. ¿Qué hace PUBLISH?

PUBLISH procesa una lista de hojas en lote; PLOT imprime un solo dibujo a la vez.

5. En el Editor de bloques (BEDIT), ¿qué pasos crean un bloque dinámico?

BEDIT abre el editor: se define el parámetro, se le asigna una acción (estirar, girar, visibilidad) y se guarda con BSAVE.
