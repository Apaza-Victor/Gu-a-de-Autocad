El rectángulo es una polilínea con forma de cuatro lados en ángulo recto, dibujada en un solo paso. Admite opciones útiles como dimensiones exactas, área, chaflanes y esquinas redondeadas, y sigue siendo un único objeto para seleccionar y editar.

1. Ejecutar el comando

CómoQué escribirAtajo
Barra de comandosRECTÁNGULO (en inglés: RECTANG)REC
Cinta → Inicio → DibujoIcono de rectánguloClic

2. Cómo se usa

1

Dos esquinas opuestas

RECTÁNGULO (en inglés: RECTANG) → clic donde va una esquina → clic (o coordenada relativa @100,60) en la esquina opuesta.

2

Con dimensiones exactas

Teclea la opción D (Dimensiones) → ancho y alto (p. ej. 100, 60) → clic para colocarlo (4 direcciones posibles alrededor del primer punto).

3

Esquinas redondeadas o chaflán

Con las opciones C (Chaflán) o R (Redondear) defines esquinas biseladas o curvas; ideales para muebles y piezas mecanizadas: R → radio 8 → dibuja.

3. Mini ejercicio

1

Una habitación 300×400

REC → clic en una esquina → opción D → ancho 300, alto 400 → clic para colocarla a la derecha-arriba.

2

Un tablero de mesa redondeado

Dibuja otro rectángulo 120×60 con la opción R y radio 12 en las esquinas.

Error común Pensar que el rectángulo siempre va "horizontal". Puedes girar la colocación con la opción R (Rotación) o simplemente dibujarlo y luego usar GIRAR (en inglés: ROTATE) con ORTO apagado.
