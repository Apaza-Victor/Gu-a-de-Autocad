10Agrupar objetos: GROUP y grupos con nombre

Un grupo es un conjunto de objetos que se comportan como una unidad temporal: los seleccionas de un solo clic, los mueves, copias y escalas juntos, pero no se definen como bloque (no se puede insertar ni es un "archivo"). Es la herramienta ideal para agrupaciones rápidas de trabajo.

Grupo vs Bloque El bloque es la solución definitiva para elementos reutilizables (una puerta, una ventana). El grupo es para agrupar objetos temporalmente en el archivo actual, sin crear una definición. Primero agrupar, luego convertir en bloque si va a repetirse.

1. Crear un grupo rápido (paso a paso)

1

Selecciona los objetos

Con una ventana o haciendo clic a varios objetos. Sostén Shift para quitar alguno de la selección.

2

Ejecuta GROUP

Escribe GRUPO (en inglés: GROUP) o G en la línea de comandos y pulsa Enter.

3

Confirma la creación

AutoCAD crea el grupo (en versiones recientes abre el cuadro de diálogo; pulsa Aceptar). A partir de ahora, un clic sobre cualquier miembro selecciona el grupo completo.

2. Crear grupos con nombre

Para gestionar varios grupos, usa la versión en cuadro de diálogo: escribe CLASSICGROUP o GRUPO (en inglés: GROUP) y pulsa Enter (en AutoCAD 2020+ usa GRUPO (en inglés: GROUP) y luego la opción "Con nombre" desde la barra de grupos de la cinta, en Inicio → Grupo).

1

Abre el cuadro de diálogo

Escribe CLASSICGROUP y pulsa Enter, o en la cinta: Inicio → Grupo → menú → y pulsa la pequeña flecha del panel.

2

Ponle nombre y descripción

En "Nuevo grupo", escribe un nombre lógico (ej.: Conjunto-Cocina) y una descripción. El nombre permite buscar el grupo después.

3

Añade los objetos

Pulsa "Seleccionar objetos", selecciona en el dibujo y pulsa Enter. El grupo queda registrado con su nombre.

3. Editar, desagrupar y borrar grupos

  • Desagrupar uno: escribe UNGROUP y pulsa Enter (selecciona el grupo). Los objetos quedan sueltos.
  • Desagrupar todos: escribe UNGROUP y elige la opción Todos (o N en algunos idiomas).
  • Añadir o quitar miembros: con GROUPEDIT (o doble clic sobre un grupo) eliges Añadir objetos o Quitar objetos.
  • Renombrar: en el cuadro de diálogo, selecciona el grupo, pulsa "Renombrar" y escribe el nombre nuevo.

4. Por qué a veces "no agrupa" (solución de problemas)

SíntomaCausa probableSolución
Al pulsar un objeto se selecciona solo él, no el grupoLa variable PICKSTYLE tiene valor 0 (los grupos desactivados)Escribe PICKSTYLE y ponlo en 1 (o 3 para combinar grupos + asociatividad)
El grupo aparece pero "no se mueve como uno"La variable PICKSTYLE = 1 pero seleccionas con ventana que corta el grupoRevisa que marques objetos dentro completos; o activa GROUPSON
GROUP no hace nada visibleSe creó un grupo sin nombre y se perdió entre otrosAbre CLASSICGROUP y revisa la lista; renómbralo ahí
Al copiar/pegar el grupo se desarmaEl portapapeles de Windows no conserva gruposUsa COPYBASE (Ctrl+Shift+C) o guarda/inserta como bloque BLOQUEDISC (en inglés: WBLOCK)
No encuentro el grupo para editarloNo tiene nombre o está anidadoEn -GRUPO (en inglés: -GROUP) (línea de comandos) usa la opción ? para listar todos los grupos del dibujo
Atención Un bloque y un grupo no se mezclan. Si dentro de un grupo metes un bloque, el grupo agrupa la inserción. Para editar el bloque en sí, entra en el editor de bloques (BEDIT).

5. Agrupar correctamente y con nombre (flujo recomendado)

  1. Selecciona los objetos de la unidad funcional (ej.: la mesa con sus sillas).
  2. Ejecuta GRUPO (en inglés: GROUP) y guárdalo siempre con nombre (ej.: Comedor-01).
  3. Mientras definas el dibujo, muévelo como grupo; no lo rompas.
  4. Si el elemento se repetirá en el proyecto, convierte el grupo en bloque con BLOQUE (en inglés: BLOCK) (B) y reutilízalo.
