Aprende paso a paso

Tips y tutoriales de AutoCAD

Guías prácticas con diagramas y comandos esenciales para dominar AutoCAD desde lo básico.

Geometría Dibujar una línea

El comando LINE (atajo L) dibuja segmentos rectos conectados. Define el punto inicial, luego el siguiente punto y repite hasta terminar. Presiona Enter o ESC para finalizar.

LINE
ENTER
Consejo Escribe coordenadas relativas con @ (ej: @100,0) para dibujar líneas exactas sin helpers.

Geometría Dibujar un círculo

El comando CIRCLE (atajo C) crea círculos definidos por centro y radio. También puedes usar diámetro escribiendo D después de indicar el centro.

Consejo Usa 2P o 3P como opciones para definir el círculo por diámetro o por tres puntos en su perímetro.

Geometría Dibujar un rectángulo

El comando RECTANG (atajo REC) crea rectángulos definiendo dos esquinas opuestas. Opciones como F (fillet) y D (dimensiones) amplían su uso.

RECTANG
D/DIMS
Consejo Después del primer punto, escribe @ancho,alto (ej: @200,100) para crear un rectángulo con dimensiones exactas.

Geometría Polilínea desde cero

Una polilínea conecta múltiples segmentos como una sola entidad. Se puede cerrar con la opción C. Usa PLINE o PL, haz clic en cada vértice.

PLINE
C / Close
Consejo Puedes darle grosor con la opción W (width) al inicio del comando.

Geometría Dibujar un arco

ARC dibuja arcos de 3 puntos: inicio, punto intermedio, fin. También soporta Centro-Inicio-Fin.

Consejo El atajo A + Enter usa el método de 3 puntos por defecto.

Geometría Dibujar una Spline

SPLINE crea curvas suaves y fluidas que pasan por puntos de control. Ideal para contornos orgánicos.

Consejo Pulsa Enter 3 veces para definir puntos inicial, final y tangentes.

Geometría Líneas de boceto

XLINE crea líneas infinitas de construcción. RAY crea rayos en una dirección. Sirven como guías de alineación.

Consejo No se imprimen por defecto. Úsalas como guías y borra después.

Geometría Dibujar una elipse

ELLIPSE (atajo EL) crea elipses definiendo los ejes mayor y menor. Centro o extremos.

Consejo Usa la opción Centro (C) para definir desde el centro en vez de un extremo.

Geometría Dibujar un punto

POINT (atajo PO) marca puntos de referencia en el dibujo. Son visibles gracias al estilo de punto PDMODE.

Consejo Cambia PDMODE a 3 o 34 para que los puntos se vean mejor en pantalla.

Geometría Dibujar un rayo

RAY crea un rayo infinito en una dirección desde un punto base. Perfecto para ejes de construcción.

Consejo Combina RAY con ORTO (F8) para crear ejes perfectamente horizontales o verticales.

Edición Copiar objetos

Selecciona los objetos, define un punto base y haz clic en el destino. El comando COPY se repite automáticamente; pulsa ESC para salir.

ORIGINAL
COPIAS
Consejo Activa ORTO (F8) para copiar alineado a ejes. Escribe N antes de los clics para indicar el número de copias.

Edición Crear copia de simetría (MIRROR)

Selecciona los objetos y define el eje de simetría con 2 puntos. El comando MIRROR genera la copia reflejada.

ANTES
RESULTADO
Consejo Al finalizar, responde S para conservar el original o N para moverlo como espejo.

Edición Mover objetos

Selecciona objetos, elige un punto base y arrastra al destino. El comando MOVE traslada sin duplicar.

ANTES
DESPUÉS
Consejo Con ORTO activo, el movimiento se restringe a ejes ortogonales. Usa @x,y para desplazamientos relativos precisos.

Edición Crear copia de desfase (OFFSET)

Especifica una distancia y selecciona un objeto; el comando OFFSET crea una paralela a esa distancia.

DISTANCIA
RESULTADO
Consejo Haz clic a un lado u otro de la línea para elegir la dirección. Puedes seguir creando copias con clics sucesivos.

Edición Recortar objetos (TRIM)

El comando TRIM recorta segmentos que se extienden más allá de los bordes de corte. Pulsa ENTER para modo rápido.

ANTES
RESULTADO
Consejo En AutoCAD moderno (2021+), pulsa ENTER directamente para que todos los objetos sean bordes de corte.

Edición Redondear esquinas (FILLET)

El comando FILLET crea un arco de radio R entre dos líneas. Con Radio=0 genera esquinas perfectas.

ANTES
RESULTADO
Consejo Con radio=0, FILLET une dos líneas formando esquina perfecta. Usa P para aplicar a todos los vértices de una polilínea.

Edición Estirar un objeto (STRETCH)

Selecciona con ventana cruzante. Los vértices dentro se mueven; los fuera se mantienen. El comando STRETCH deforma proporcionalmente.

VENTANA
ESTIRADO
Consejo La ventana cruzante (de derecha a izquierda, borde discontinuo) es clave. Solo los vértices capturados se desplazan.

Edición Crear una matriz (ARRAY)

El comando ARRAY crea múltiples copias en filas/columnas (rectangular) o en patrón circular (polar).

Consejo La matriz es editable y asociativa: ajusta filas, columnas y espaciado desde la cinta de opciones tras crearla.

Edición Unir y descomponer objetos

JOIN (J) une líneas contiguas en una sola. EXPLODE (X) descompone polilíneas, bloques y cotas en elementos básicos.

UNIR
DESCOMPONER
Consejo JOIN funciona con líneas que comparten un punto final exacto. Usa F3 (OSNAP) para verificar la conexión.

Capas Crear capa con color

LAYER abre el administrador de capas. Crea capas con nombre, color, tipo de línea y grosor para organizar tu dibujo.

Consejo Usa colores distintos por capa para identificar rápidamente elementos. Nunca dibujes todo en la capa 0.

Capas Encender / Apagar capas

LAYON enciende todas las capas. LAYOFF apaga la capa que selecciones.

VISIBLE
LAYOFF
Consejo Apaga capas de referencia antes de imprimir para que no aparezcan en el plotscape.

Capas Aislar capas

LAYISO aísla las capas que selecciones: solo esas permanecen visibles. LAYUNISO restaura el estado anterior.

ANTES
LAYISO
Consejo LAYISO es ideal para trabajar sin distracciones. No olvides LAYUNISO para restaurar todo.

Capas Bloquear capas

LAYLOCK bloquea una capa para que sea visible pero no editable. LAYUNLOCK la desbloquea.

Consejo Bloquea capas de referencia o ejes para evitar ediciones accidentales.

Capas Copiar propiedades

MATCHPROP (atajo MA) copia propiedades de un objeto a otro: capa, color, tipo de línea, grosor.

FUENTE
DESTINO
Consejo Selección múltiple: haz clic en varios destinos tras elegir la fuente para aplicar las mismas propiedades a todos.

Capas Grosor de línea

El grosor de línea (LWEIGHT) controla el espesor de los trazos al imprimir. Se asigna por capa o por objeto.

Consejo Activa la visualización de grosores con el ícono en la barra de estado. Asigna grosores por capa para consistencia.

Capas Transparencia

La transparencia (0-90) controla la opacidad de objetos o capas. Útil para superponer información sin ocultar el fondo.

Consejo La transparencia no se imprime por defecto. Activa «Imprimir transparencia» en el diálogo de plot.

Capas Tipos de línea

LINETYPE carga y gestiona tipos: continua, punteada, decenter, fantasma, etc.

Consejo Los tipos de línea se escalan con LTSCALE. Ajusta este valor hasta que el patrón sea visible en pantalla.

Capas Panel de propiedades

PROPERTIES (atajo Ctrl+1) abre el panel con todas las propiedades del objeto seleccionado: capa, color, coordenadas, etc.

Consejo Selecciona varios objetos para editar propiedades comunes de forma masiva desde el panel.

Capas Propiedades rápidas

Al seleccionar un objeto, aparecen propiedades clave en un panel flotante. Edita color, capa, escala y más sin abrir el panel completo.

Consejo Activa Quick Properties con QPMODE o el ícono en la barra de estado. Aparece al seleccionar cualquier objeto.

Acotación Medir área

AREA calcula el área y perímetro de una región. Selecciona puntos o un objeto cerrado.

Consejo Haz clic en los vértices del polígono en orden. El comando muestra el área acumulada en tiempo real.

Acotación Medir distancia

DIST (atajo DI) mide la distancia entre dos puntos: ΔX, ΔY, ΔZ y distancia total.

Consejo Usa DIST + OSNAP para medir entre puntos exactos de geometría (vértices, centros, intersecciones).

Acotación Acotar

DIM crea cotas automáticamente: detecta líneas, círculos y ángulos. Muévete para elegir tipo y posición.

Consejo DIM es inteligente: selecciona un objeto y arrastra para elegir entre cota lineal, radial, angular o diametral.

Acotación Cota alineada

DIMALIGNED crea una cota paralela al objeto, ideal para líneas inclinadas.

Consejo DIMALIGNED mide la distancia real del segmento inclinado, no la distancia horizontal como DIMLINEAR.

Acotación Cotas continuas

DIMCONTINUE añade cotas en cadena desde la última cota creada.

Consejo Crea la primera cota con DIM, luego ejecuta DIMCONTINUE y haz clic en los puntos sucesivos.

Acotación Estilo de cota

DIMSTYLE (atajo D) configura apariencia de cotas: tamaño de texto, flechas, precisión, offset.

Consejo Crea estilos personalizados por escala de plano. Ej: uno para 1:100 y otro para 1:50 con tamaños distintos.

Acotación Escalar objeto

SCALE (atajo SC) cambia el tamaño de un objeto por un factor numérico o referencia.

×0.5
×2
Consejo Usa «Referencia» (R) para escalar un objeto a una medida exacta sin calcular el factor manualmente.

Texto Texto multilínea

MTEXT (atajo T) crea un bloque de texto editable con formato: negrita, alineación, viñetas, columnas.

Consejo MTEXT abre un editor en pantalla. Usa la barra de herramientas para formato rico: fuentes, colores, alineación.

Texto Texto en círculo o arco

ARCTEXT coloca texto siguiendo una curva o arco. Ideal para rotuladores y sellos técnicos.

Consejo ARCTEXT es un comando Express. Actívalo con EXPRESS > Text > Arc-Aligned Text.

Texto Máscara de texto

TEXTMASK coloca un fondo opaco detrás del texto para que sea legible sobre líneas y bloques.

Consejo Configura el offset de la mascara con TEXTMASKOFFSET para ajustar el espacio alrededor del texto.

Texto Enviar al frente

DRAWORDER cambia el orden de visualizacion de objetos: enviar atras, traer al frente, sobre o bajo otro objeto.

ATRAS
FRENTE
Consejo Haz clic derecho, Orden de dibujo para acceso rapido. Util cuando textos quedan ocultos bajo bloques.

Texto Sombreado / Hatch

HATCH (atajo H) rellena areas cerradas con patrones: lineas, solido, gradientes o patrones personalizados.

Consejo Haz clic dentro de un area cerrada para rellenar. Usa T para ajustar patron, angulo y escala.

Vista Hacer zoom

ZOOM (atajo Z) controla la vista: E (extents), A (all), W (window). La rueda del mouse tambien hace zoom.

Consejo Z + E (Zoom Extents) muestra todo el dibujo. Doble clic en la rueda del mouse hace lo mismo.

Vista Modo ortogonal

ORTHO (F8) restringe el cursor a ejes horizontales y verticales. Esencial para dibujar lineas rectas alineadas.

ORTO OFF
ORTO ON
Consejo Alterna ORTO rapido con F8. Para angulos especificos usa POLAR (F10) en su lugar.

Vista Varias ventanas de dibujo

TILEMODE alterna entre espacio modelo y papel. MVIEW crea ventanas de vista en el layout.

Consejo En el layout, doble clic dentro de una ventana para entrar al modelo y ajustar la vista y escala de cada una.

Vista Configurar unidades

UNITS abre el dialogo de unidades. Define el formato (decimal, fraccion), precision y sistema de medicion.

Consejo Configura unidades al inicio del proyecto para evitar problemas de escala al imprimir o insertar bloques.

Edicion Agregar texturas / Hatch paso a paso

Para rellenar un area con un patron o textura sigue estos pasos:

Paso 1: HATCH
Paso 2: Seleccionar
Consejo En el Editor de Hatch puedes cambiar patron, angulo, escala y color. Usa Previsualizar antes de confirmar con Enter.

Edicion Escalar cualquier bloque paso a paso

Para cambiar el tamano de un bloque a una medida exacta:

Seleccionar
SC + R
Consejo Usa la opcion Referencia (R) para escalar a una medida exacta sin calcular factores. Ej: si mide 1500 y necesitas 3000, usa R y clic en los extremos.

Edicion Igualar tamano de bloques paso a paso

Para que un bloque tenga el mismo tamano que otro bloque o dibujo de referencia en tu proyecto:

Mide la referencia
SC + R + 2500
Consejo Tambien puedes usar ALIGN (AL) para mover y escalar un bloque automaticamente a la referencia. Selecciona puntos源 y destino.

Acotacion Configurar DIMSTYLE / ACOESTIL paso a paso

DIMSTYLE (español: ACOESTIL) abre el Administrador de Estilos de Cota para controlar como se ven tus acotaciones: texto, flechas, precisión y más.

Paso 1: DIMSTYLE
Paso 2: Nuevo
Consejo Después de configurar, haz clic en "Cerrar" y luego escribe D → selecciona tu estilo → "Actual" para activarlo. Todas las cotas nuevas usarán ese estilo.

Edición Purgar elementos no usados

PURGE (atajo PU) elimina tipos de línea, bloques, dimensiones y estilos de texto que no están en uso en el dibujo. Reduce tamaño del archivo y mejora el rendimiento.

Consejo Secuencia: PU → Enter → verifica "Entidades anidadas" y "Objetos no referenciados" → Enter para purgar todo. Repite 2-3 veces hasta que no quede nada por purgar.

Edición Eliminar duplicados

OVERKILL (atajo OV) elimina objetos superpuestos y duplicados: líneas coincidentes, círculos duplicados y polilíneas parciales. Limpia tu dibujo de geometría redundante.

Consejo Secuencia: OV → Enter → seleccionar todo (o área) → Enter → ajusta tolerancia en el diálogo → OK. Ideal después de pegar dibujos de otras fuentes.

Geometría Crear borde / Boundary

BOUNDARY (atajo BO) crea una polilínea cerrada desde un punto dentro de un área completamente cerrada. Útil para calcular áreas y crear masas.

Consejo Secuencia: BO → Enter → haz clic en "Punto" → clic dentro del área cerrada → Enter. La polilínea nueva se superpondrá sobre el contorno existente.

Edición Selección rápida / QSELECT

QSELECT abre un diálogo de selección avanzada. Filtra objetos por tipo, capa, color, longitud y otras propiedades. Encuentra y selecciona rápidamente elementos específicos.

Consejo Acceso: clic derecho → "Selección rápida" o escribe QSELECT. Combina filtros (ej: "Capa = MUROS" + "Tipo = Línea") para selecciones precisas en dibujos complejos.

Edición Editar polilínea / PEDIT

PEDIT (atajo PE) edita polilíneas existentes: cambiar grosor, cerrar, unir segmentos, simplificar vértices y convertir líneas en polilíneas.

Consejo Para unir líneas: PE → Enter → M (múltiple) → seleccionar líneas → Enter → J (unir) → Enter ×2. Para cambiar grosor: W → grosor → Enter.

Capas Mover a capa / LAYMCH

LAYMCH mueve objetos seleccionados a otra capa de forma rápida. Selecciona los objetos y luego la capa destino. Corrige errores de organización sin desplazamiento.

Consejo Secuencia: LAYMCH → Enter → seleccionar objetos a mover → Enter → clic en un objeto de la capa destino (o seleccionar capa del diálogo). Ideal para reorganizar dibujos desordenados.

Acotación Multilínea de cota / MLEADER

MLEADER (atajo MLE) crea anotaciones con flecha y texto de una sola pasada. Combina líder, línea de base y texto multilínea en un solo objeto editable.

Consejo Secuencia: MLE → Enter → clic punta de flecha → clic posición del texto → escribe contenido → Enter. Para editar: doble clic en el texto. Cambia estilo con MLEADERSTYLE.

Edición Copiar anidados / NCOPY

NCOPY copia objetos que están dentro de bloques, referencias externas (XREF) o referencias de diseño sin descomponer el bloque. Selecciona directamente el objeto anidado.

Consejo Secuencia: NCOPY → Enter → clic en el objeto dentro del bloque → Enter. El objeto se copia como entidad independiente en el espacio actual. Ideal para extraer geometría de XREFs.

Vista Recortar XREF / XCLIP

XCLIP recorta la visualización de referencias externas (XREF) y bloques con atributos. Define un área rectangular, poligonal o circular para mostrar solo esa porción.

Consejo Secuencia: XCLIP → Enter → seleccionar XREF o bloque → Enter → elige forma (Rect/Polygon/Circle) → define el área. Para editar: clic en el borde de recorte → ajusta vértices.

Vista Aplanar 3D a 2D / FLATTEN

FLATTEN convierte objetos 3D a 2D proyectándolos sobre el plano XY actual. Elimina coordenadas Z y mantiene la geometría visible en planta.

Consejo Secuencia: FLATTEN → Enter → ajusta opciones (Eliminar líneas ocultas: Sí) → Enter. Antes de ejecutar, guarda una copia por si necesitas revertir. Elimina aristas ocultas si lo deseas.

Edición Ocultar líneas detrás de bloques / WIPEOUT

WIPEOUT (atajo WI) crea un área enmascarada que oculta los objetos detrás de ella. Ideal para que un bloque (ej: un auto) tape las líneas de un plano sin necesidad de recortar.

Consejo _WIPEOUT / COBERTURA → _DRAWORDER / ORDENAOBJETOS → _WIPEOUTFRAME (igual en todas las versiones) → BCLOSE / CERRARBLOQUE

Capas Eliminar capas con objetos / LAYDEL

LAYDEL (comando Express) elimina una capa completa junto con todos los objetos que contiene. A diferencia de PURGE, que solo elimina capas vacías, LAYDEL fuerza la eliminación aunque la capa tenga geometría.

Consejo 1. LAYDEL → Enter. 2. Selecciona objeto o escribe nombre de capa. 3. S (Sí) → Enter. Usa LAYMCH para mover objetos antes.

Edición Unir medidas y escalar bloques / SCALE + ALIGN

Cuando agregas bloques de otra fuente, pueden tener unidades diferentes (metros vs. milímetros). Usa SCALE (atajo SC) para ajustar el tamaño o ALIGN (atajo AL) para escalar y posicionar automáticamente.

Consejo Método 1: SC → factor (2, 0.5, 0.001). Método 2: SC → R → 2 puntos → medida real. Método 3: AL → 2 pares de puntos → S.
